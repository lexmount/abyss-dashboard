# Public website and standalone dashboard

The regional product footers and their policy links belong to the public
website. Its localized open-source overview describes the endpoint runtime's
MIT license. The dashboard README links readers to that overview. The
standalone dashboard serves the local operator's activity data and keeps
its existing navigation and API contracts.

The [frontend design](https://github.com/lexmount/abyss-frontend/blob/task/fix-official/docs/fix-official.md)
covers domain selection, terminology and validation. The documentation link
uses an existing public route and can ship independently of the frontend change.
